# Bibliothèque d'annexes

Les annexes constituent un espace de réflexion libre, distinct du manifeste officiel.

Chaque contribution peut être proposée sans validation préalable de sa thèse, sous réserve d'une modération minimale contre les abus et la divulgation de données personnelles.

Statuts de discussion possibles :
- **Non examinée** : publiée sans discussion critique documentée.
- **En discussion** : échanges et objections en cours.
- **Examinée** : discussion critique documentée, sans approbation automatique.
- **Contestée** : objections importantes ouvertes.
- **Archivée** : conservée pour l'historique.

Les auteurs conservent leur attribution ; les modifications et les discussions doivent rester traçables. Une annexe n'engage pas automatiquement le projet.
