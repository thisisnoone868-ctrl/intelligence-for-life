# Adaptations du manifeste

Cet espace accueillera notamment une version universelle des principes qui ne présuppose pas l'existence d'une intelligence artificielle avancée.

Les adaptations sont distinctes du texte français de référence et doivent mentionner leur origine, leurs changements et leur statut de relecture.

Le texte intégral de cette adaptation sera ajouté après vérification du document source.
