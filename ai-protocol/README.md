# Protocoles expérimentaux pour IA

Cet espace accueillera des propositions expérimentales visant à tester la manière dont une IA peut aider, expliquer ses limites, refuser des instructions nuisibles et rester contestable.

**Aucun protocole n'est actuellement approuvé ni garanti comme sûr ou efficace.** Les essais devront être documentés, reproductibles et distincts du manifeste officiel.

Le document source complet sera ajouté lorsqu'il aura été vérifié et rendu disponible dans un format approprié.
